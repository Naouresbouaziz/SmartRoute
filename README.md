# 🧠 SmartRoute Sousse

Personalized Multimodal Transportation Optimizer for Sousse, Tunisia.

## 🎯 Objective

SmartRoute Sousse helps users find transportation routes based on
their personal constraints and preferences.

The system does not simply search for the shortest route.

It considers:

- Travel time
- Price
- Walking distance
- Number of transfers
- Reliability
- User preferences

## 🚐 Initial transportation modes

- Louage
- Bus
- Taxi

## 🗺️ Initial geographic area

Sousse and surrounding areas.
